# Karban Mobile

React + Vite + Tauri 2, Persian/RTL first. Customer registration is the only direct account registration. Business mode is enabled from the "ساخت پروفایل کسب‌وکار" flow after the customer account exists.

Run web shell: `npm install && npm run dev`

Initialize/build Android (requires Rust, Android SDK/NDK and Tauri prerequisites):

```bash
npm run tauri:android:init
npm run tauri:android:dev
npm run tauri:android:build
```
